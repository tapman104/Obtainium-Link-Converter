Runs locally in your browser; it does not upload the details you type. GitHub lookups use GitHub's API/raw file host. IzzyOnDroid lookups read the app's YAML file from its public repodata repository (AuthorName and Name/AutoName), without scraping the app page or using a third-party CORS proxy. F-Droid lookups read the app's Name/AutoName and AuthorName from F-Droid's fdroiddata metadata (mirrored on GitHub and GitLab). The generated link only imports a source configuration. Obtainium/Android may still ask you to confirm installation. Check the package ID, APK architecture and signing certificate before updating an existing installation.
